# Phase 2 – Requirement Analysis

## Project Title
AI Fit Track

## Problem Statement
Users may find it difficult to maintain and monitor their daily fitness activities in one place. AI Fit Track provides a simple web-based solution to track important fitness information.

## Functional Requirements

### 1. User Registration
- Users can create an account by providing basic details.
- User information is stored using browser local storage.

### 2. User Login
- Registered users can log in using their credentials.
- The dashboard is accessible after successful login.

### 3. BMI Calculator
- Users can enter their height and weight.
- The system calculates the Body Mass Index (BMI).
- BMI-based fitness information is displayed.

### 4. Workout Tracking
- Users can track daily workouts such as running, stretching and squats.
- Workout status can be updated by the user.

### 5. Exercise Tracking
- Users can track exercises such as push-ups, plank and lunges.

### 6. Daily Activity Tracking
- Users can enter daily steps and calorie information.
- The dashboard displays the entered activity information.

### 7. Water Intake Tracking
- Users can enter their daily water intake.
- The system displays water progress.

### 8. Fitness Recommendation
- The system provides fitness recommendations based on BMI.

### 9. Diet Recommendation
- The system provides basic diet recommendations based on BMI.

### 10. Daily Calorie Goal
- The system displays a daily calorie goal for the user.

## Non-Functional Requirements
- Simple and user-friendly interface.
- Easy navigation between pages.
- Fast response in the browser.
- Works on modern web browsers.
- Responsive and readable design.
- Easy to maintain and update.

## Software Requirements
- HTML
- CSS
- JavaScript
- Visual Studio Code
- Web Browser
- GitHub

## Hardware Requirements
- Computer or laptop
- Keyboard and mouse
- Internet connection for development and GitHub access

## Target Users
- Students
- Beginners
- People interested in monitoring their daily fitness activities

## Inputs
- User registration details
- Login credentials
- Height and weight
- Workout activities
- Exercise activities
- Daily steps
- Calories
- Water intake

## Outputs
- BMI result
- Workout status
- Exercise progress
- Daily activity information
- Water progress
- Fitness recommendation
- Diet recommendation
- Daily calorie goal

## Expected Outcome
AI Fit Track provides users with a simple web-based platform to monitor their fitness activities and view basic personalized recommendations.
