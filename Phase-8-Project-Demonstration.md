# Phase 8 – Project Demonstration

## Project Title
AI Fit Track

## Demonstration Objective
The project demonstration explains the purpose, features and working process of the AI Fit Track application.

## Demonstration Flow

### 1. Project Introduction
- Introduce the project name: AI Fit Track.
- Explain the purpose of the application.
- Explain how the application helps users track their daily fitness activities.

### 2. Home Page Demonstration
- Open the AI Fit Track home page.
- Explain the navigation menu.
- Show the main features of the application.

### 3. User Registration
- Open the registration page.
- Demonstrate entering user details.
- Show successful registration.

### 4. User Login
- Open the login page.
- Enter the registered credentials.
- Demonstrate successful login.

### 5. Fitness Dashboard
- Show the main dashboard.
- Explain the available fitness tracking features.

### 6. BMI Calculator
- Enter height and weight.
- Calculate BMI.
- Explain the displayed BMI result and recommendation.

### 7. Workout and Exercise Tracking
- Demonstrate workout tracking.
- Show running, stretching and squats.
- Demonstrate exercise tracking such as push-ups, plank and lunges.

### 8. Daily Activity Tracking
- Enter daily steps.
- Enter calorie information.
- Show the updated dashboard information.

### 9. Water Intake Tracking
- Enter daily water intake.
- Demonstrate the water progress bar.
- Explain the displayed water progress.

### 10. Recommendations
- Demonstrate fitness recommendation.
- Demonstrate diet recommendation.
- Show the daily calorie goal.

### 11. Logout
- Demonstrate the logout option.
- Show that the user can safely return from the dashboard.

## Video Demonstration Requirements
The demonstration video should include:
- Screen sharing
- Student voice-over
- Project name
- Project purpose
- Main features
- Project execution and working process
- Final output

## Expected Demonstration Output
The final demonstration should show the complete working flow of AI Fit Track from the home page to login, fitness tracking, recommendations and logout.

## Conclusion
The project demonstration presents the complete working process and major features of the AI Fit Track application.
