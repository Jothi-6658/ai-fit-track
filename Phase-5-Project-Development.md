# Phase 5 – Project Development

## Project Title
AI Fit Track

## Development Overview
AI Fit Track was developed as a web-based fitness tracking application using HTML, CSS and JavaScript.

## Development Process

### 1. Project Setup
- Created the project folder.
- Created the required HTML files.
- Set up the basic website structure.
- Connected the pages through navigation links.

### 2. Home Page Development
- Created the AI Fit Track home page.
- Added project introduction.
- Added navigation menu.
- Added fitness feature sections.
- Added Start Tracking option.

### 3. Registration Development
- Created the user registration page.
- Added input fields for user details.
- Implemented browser local storage for basic user information.

### 4. Login Development
- Created the login page.
- Added username and password validation.
- Connected login with the fitness dashboard.
- Added logout functionality.

### 5. Fitness Dashboard Development
The dashboard was developed with the following features:
- BMI Calculator
- Daily Workout Tracking
- Exercise Tracking
- Daily Steps
- Calories
- Water Intake
- Water Progress
- Fitness Recommendation
- Diet Recommendation
- Daily Calorie Goal

### 6. BMI Calculator
- Added height and weight input fields.
- Implemented BMI calculation using JavaScript.
- Displayed the calculated BMI result.
- Added BMI-based recommendations.

### 7. Workout and Exercise Tracking
- Added workout activities such as running, stretching and squats.
- Added exercises such as push-ups, plank and lunges.
- Added options to track daily activities.

### 8. Water Tracking
- Added water intake input.
- Added water progress calculation.
- Added a visual progress bar.
- Displayed the percentage of daily water progress.

### 9. Recommendation Features
- Added fitness recommendations based on BMI.
- Added diet recommendations based on BMI.
- Added daily calorie goal information.

### 10. JavaScript Implementation
JavaScript was used to:
- Process user inputs.
- Perform BMI calculations.
- Update dashboard information.
- Track fitness activities.
- Calculate water progress.
- Display recommendations.
- Manage login and logout functionality.

## Development Tools
- HTML
- CSS
- JavaScript
- Visual Studio Code
- GitHub
- Web Browser

## Final Development Output
The completed application provides a single web-based platform where users can log in and track their basic fitness activities, view progress and receive fitness-related recommendations.
