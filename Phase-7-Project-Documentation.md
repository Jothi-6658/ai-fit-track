# Phase 7 – Project Documentation

## Project Title
AI Fit Track

## Project Overview
AI Fit Track is a web-based fitness tracking application designed to help users monitor their daily fitness activities and view basic fitness-related recommendations.

## Project Purpose
The main purpose of AI Fit Track is to provide users with a simple platform for tracking important fitness activities such as BMI, workouts, exercises, steps, calories and water intake.

## Technologies Used
- HTML
- CSS
- JavaScript
- Visual Studio Code
- GitHub
- Browser Local Storage

## Main Features
- User Registration
- User Login
- BMI Calculator
- Workout Tracking
- Exercise Tracking
- Daily Steps Tracking
- Calories Tracking
- Water Intake Tracking
- Water Progress
- Fitness Recommendation
- Diet Recommendation
- Daily Calorie Goal
- Logout

## Target Users
The application is designed for students, beginners and people who want to monitor their daily fitness activities.

## Project Workflow

1. User opens the AI Fit Track website.
2. User registers an account.
3. User logs in using the registered credentials.
4. User enters fitness information.
5. The application processes the information using JavaScript.
6. BMI and fitness-related results are displayed.
7. User can track workouts, exercises, steps, calories and water intake.
8. The application displays progress and recommendations.

## Project Files

### index.html
Contains the home page and project introduction.

### login.html
Provides the user login interface.

### register.html
Provides the user registration interface.

### fitness.html
Contains the main fitness dashboard and tracking features.

## Data Storage
Basic user and login-related information is stored using browser Local Storage.

## Testing
The main application features were tested during development, including registration, login, BMI calculation, workout tracking, exercise tracking, water tracking and recommendations.

## Project Benefits
- Simple and easy-to-use interface.
- Combines multiple fitness tracking features in one application.
- Provides basic personalized recommendations.
- Helps users monitor their daily fitness activities.

## Project Status
The main project features have been developed and tested successfully.

## Conclusion
AI Fit Track provides a simple web-based solution for monitoring daily fitness activities and viewing basic fitness and diet recommendations. The project demonstrates the use of HTML, CSS and JavaScript to build an interactive fitness application.
